Alleen voor jou. Met een token van GitHub sla je ritten rechtstreeks op, zonder kopiëren en plakken.

Laden…

Zo maak je een token

  1. Open op GitHub de pagina voor een nieuw token: nieuw fine-grained token maken. Werkt de link niet, ga dan via je profielfoto rechtsboven naar Settings, dan helemaal onderaan links Developer settings, Personal access tokens, Fine-grained tokens en Generate new token.
  2. Geef het token een naam, bijvoorbeeld Achtbanensite telefoon. Kies bij Expiration hoe lang hij geldig blijft, bijvoorbeeld een jaar. Daarna maak je gewoon een nieuwe.
  3. Kies bij Resource owner je eigen account.
  4. Kies bij Repository access voor Only select repositories en selecteer alleen RuDeMer/achtbanen.
  5. Zet bij Permissions (onder Repository permissions, of via Add permissions) Contents op Read and write. GitHub zet er zelf Metadata: Read-only bij; dat hoort zo. Laat de rest uit.
  6. Klik op Generate token en bevestig. Kopieer het token: het begint met github_pat_ en GitHub laat het maar één keer zien.
  7. Plak het hierboven en kies Token opslaan. De site controleert meteen of het token mag lezen en schrijven.

Het token blijft alleen in deze browser op dit apparaat. Het komt niet in de repository en niet in de code. Wil je ook vanaf je telefoon beheren, plak het daar ook (of maak voor elk apparaat een eigen token, dan kun je er één intrekken zonder de andere).

Token weer verwijderen

  1. Van dit apparaat: kies hierboven Token verwijderen. De beheerknoppen verdwijnen meteen.
  2. Helemaal intrekken: ga op GitHub naar Settings, Developer settings, Personal access tokens, Fine-grained tokens, klik op het token en kies onderaan Delete. Dan werkt het nergens meer. Doe dit meteen als je telefoon kwijt is of als je denkt dat iemand anders het token heeft.

Deze pagina staat niet in het menu. Bewaar het adres als bladwijzer.
